# 📅 Current Date Display

This is a simple JavaScript project that displays the **current date** dynamically on the web page using the `Date` object.

---

## 🚀 Features

- 📆 Automatically shows today's date
- 🕐 Uses built-in JavaScript `Date` object
- 🎨 Simple and clean UI

---

## 🛠️ Technologies Used

- **HTML** – For page structure
- **CSS** – For basic styling
- **JavaScript** – To fetch and display the current date

---

## 💻 How It Works

1. When the page loads, a JavaScript function gets the current date.
2. The date is formatted (e.g. `May 3, 2025`) and inserted into the page.
3. The displayed date updates each time the page is refreshed.
